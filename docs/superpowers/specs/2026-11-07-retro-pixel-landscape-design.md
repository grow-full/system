# 레트로 도트 + PC 가로 화면 설계

작성일: 2026-11-07 · 브랜치: `feature/yooch`

## 1. 목표

- 앱 전체를 **레트로 도트(픽셀) LCD 느낌**으로 바꾼다. 휴대용 육성 게임기의 분위기만 가져오고, 특정 제품의 캐릭터·화면·로고는 따라 하지 않는다. 주인공은 우왕이 그대로다.
- 세로(휴대폰) 화면을 **PC용 가로 화면**으로 바꾼다.
- 키우기 규칙, 저장 데이터(`localStorage`의 `wooang-travel-v2`), 게임 내용, 커뮤니티 글은 바꾸지 않는다. **모양과 배치만** 바꾼다.

### 사용자가 정한 것

| 항목 | 결정 |
|---|---|
| 적용 범위 | 앱 전체 도트 (4개 탭 모두, 우왕이도 도트로 다시 그림) |
| 색감 | 크림 LCD 바탕 + 버건디 글씨·테두리 |
| 가로 배치 | 왼쪽 세로 메뉴 + 가운데 큰 화면 + 오른쪽 패널 |
| 만드는 방법 | 화면 모양을 새로 짜고, 우왕이를 도트 SVG로 다시 그리기 (도트 필터 씌우기나 캔버스 전면 재작성은 하지 않음) |

## 2. 색과 글씨

| 이름 (CSS 변수) | 값 | 쓰는 곳 |
|---|---|---|
| `--page` | `#5e1028` | 앱 바깥 배경 |
| `--lcd` | `#f4ead6` | 화면 바탕 (크림 LCD) |
| `--lcd-dark` | `#e8dabf` | 칸 구분, 눌린 버튼, 빈 막대 |
| `--ink` | `#4a0d22` | 글씨, 도트 테두리 |
| `--primary` | `#8c1d40` | 강조, 선택된 메뉴, 주요 버튼 |
| `--primary-dark` | `#5e1028` | 주요 버튼 그림자 |
| `--sub` | `#8a6a72` | 보조 글씨 |
| `--tint` | `#f2d9df` | 선택된 항목 배경 |
| 포인트 | 연분홍 `#f4a7b9`, 하늘 `#9fd3e8` | 하트, 창문 등 작은 곳에만 |

- **LCD 질감:** 화면 바탕에 1px짜리 아주 옅은 격자선(3px 간격, 투명도 5% 안팎)을 깐다.
- **글씨체:** 한글 도트 글씨 **갈무리(Galmuri11, OFL 무료)**. 지금의 주아·고운돋움은 뺀다. 인터넷이 없으면 기본 글씨체로 보인다. 숫자 시계도 갈무리로 통일한다.
- **글씨 선명하게:** 도트 글씨가 흐려지지 않게 `-webkit-font-smoothing: none`을 주고, 글씨 크기는 갈무리가 선명한 크기(12·16·24px)만 쓴다.
- **그대로 두는 색:** 퀴즈 정답 초록·오답 빨강, 하늘, 밤 창문, 반짝 우왕이 금색.

## 3. 도트 UI 규칙

- **모서리:** 둥근 모서리(`border-radius`)는 모두 없앤다.
- **상자·버튼 테두리:** 2px 버건디 선에 모서리 한 칸을 비운 계단 모양. `box-shadow`를 여러 겹 써서 만든다.
- **그림자:** 흐림 없이 아래·오른쪽으로 딱 끊긴 3px 그림자.
- **버튼을 누르면** 그림자가 없어지고 3px 내려간다.
- **움직임:** 부드러운 애니메이션 대신 `steps()`로 뚝뚝 끊기게 한다. 걷기, 눈 깜빡임, 말풍선 등이 해당된다. 우왕이가 방을 가로질러 걷는 이동만 지금처럼 부드럽게 둔다.
- **하트:** 이모지 ❤️ 대신 도트 하트 아이콘(찬 하트/빈 하트)을 쓴다.

## 4. 가로 배치

### 4.1 전체 틀 (창 가로 900px 이상)

```
┌ 왼쪽 메뉴 200px ┬──── 가운데 (남는 폭) ────┬ 오른쪽 패널 340px ┐
│ Lv.1 ▓▓▓░░     │                          │                  │
│ ▶ 우왕이        │                          │                  │
│   여행          │                          │                  │
│   게임          │                          │                  │
│   커뮤니티      │                          │                  │
│                │                          │                  │
│ 🪙 20   🔔      │                          │                  │
└────────────────┴──────────────────────────┴──────────────────┘
```

- 앱은 창 높이에 꽉 차고(`100vh`), 가운데와 오른쪽은 **각자 따로 스크롤**된다.
- 전체 최대 폭은 1400px이고, 그보다 넓은 창에서는 가운데 정렬한다.
- 지금의 `.topbar`(Lv·경험치·알림·코인)와 `.tabbar`(탭 4개)를 **왼쪽 메뉴 하나**로 합친다. 탭 버튼은 `class="tabbar"`와 `data-tab`을 그대로 둬서 `app.js`의 탭 전환 코드를 고치지 않는다.
- 각 탭(`section.screen`)은 안에 `div.col-main`(가운데)과 `aside.col-side`(오른쪽)를 가진다. 모든 요소의 `id`는 그대로 둔다.

### 4.2 탭별 배치

| 탭 | 가운데 `col-main` | 오른쪽 `col-side` |
|---|---|---|
| 우왕이 | 우왕이 방(높이 약 420px) → 옷장·도감을 2칸으로 나란히 → 돌보는 방법 → 처음부터 다시 키우기 | 배고픔·행복 → 돌보기 버튼 8개(2열×4줄) → 안내 문구 → 말 걸기 판 / 놀아주기 판 (버튼 자리를 바꿔 끼움) |
| 여행 | 지금 단계의 화면: 여행 계획(도착지·기다릴 시간·발권) / 탑승권 / 비행(창밖·카운트다운·소리 조절) / 도착 | 내 여권 스탬프, 기념품 (모든 단계에서 늘 보임) |
| 게임 | 고른 게임 화면. 아직 안 골랐으면 "오른쪽에서 게임을 골라 주세요" 안내 | 게임 안내 문구, 게임 목록과 최고 점수 (게임 중에도 늘 보임) |
| 커뮤니티 | 꿀팁 글 목록 | 저장 방식 안내, 여행지 필터, 정렬, 꿀팁 쓰기 버튼과 글쓰기 칸 |

> 승인된 설계 요약과 달라진 점: 여행 탭은 처음 요약에서 "오른쪽 = 여행지·시간 고르기"였다. 그런데 비행·도착 화면이 계획 화면을 대신하는 구조라, 계획을 오른쪽에 두면 비행 중에 오른쪽이 비게 된다. 그래서 **계획은 가운데**, 늘 보여 줄 **여권·기념품은 오른쪽**으로 바꿨다.

### 4.3 좁은 창 (가로 900px 미만)

- 왼쪽 메뉴는 위쪽 가로 막대로 바뀐다(Lv·탭 4개·코인·알림).
- 가운데와 오른쪽은 위아래로 쌓인다. 우왕이 탭은 방 → 오른쪽 패널(상태·버튼) → 옷장·도감 순서로, 지금의 휴대폰 화면과 비슷하게 보인다.

## 5. 그림 (도트)

### 5.1 우왕이와 알

- 지금의 `MASCOT_SVG`와 `EGG_SVG`(`js/mascot.js`)를 **32×32칸 도트 그림**으로 다시 그린다. `viewBox`는 0 0 200 200 그대로 두고, 한 칸은 6.25 단위다. `shape-rendering="crispEdges"`를 쓴다.
- 도트 그림은 글자 지도(예: `'..XXXX..'`)로 적어 두고, 불러올 때 `<rect>` 묶음으로 바꾸는 작은 함수로 만든다. 나중에 실제 우왕이 도트 그림을 받으면 지도만 바꾸면 된다.
- **지금 클래스 이름을 모두 유지**한다. 그래서 `pet.js`와 CSS의 상태 표시가 그대로 동작한다.
  - `m-body`, `m-skin`(색은 그룹의 `fill`을 CSS로 바꿈), `m-eyes`, `m-pupils`, `m-eyes-closed`, `m-eyes-x`
  - `m-mouth`와 `m-happy`/`m-normal`/`m-sad`/`m-open`
  - `acc-sprout`, `acc-shiny`, `acc-traveler`, `acc-gamer`, `acc-messy`, `acc-sturdy`
  - 알은 `egg`, `crack`
- **눈동자 따라가기**는 한 칸 단위(6.25)로 끊어서 움직인다. 좌우 최대 1칸, 위아래 최대 1칸이다. `pet.js`의 `gazeAt`에서 값을 반올림한다.
- 의상(머리·얼굴·목·손 이모지)과 꼬질꼬질 얼룩은 지금처럼 그림 위에 겹친다.

### 5.2 작은 아이콘

`js/pixel-icons.js`(새 파일)에 16×16칸 도트 아이콘을 모아 두고, 같은 글자 지도 방식으로 만든다.

- **돌보기 버튼:** 밥, 간식, 놀아주기, 청소, 씻기기, 약, 불, 말 걸기
- **방 안 효과:** 똥, 밥·간식, 약, 비눗방울, 물방울, 반짝이, 파리, 아픔 표시, Z
- **기타:** 하트(찬/빈), 코인, 알림 켜짐/꺼짐, 왼쪽 메뉴의 탭 아이콘 4개

여행지 15곳과 의상 15종의 이모지, 커뮤니티·게임 안의 이모지는 이번에 바꾸지 않는다.

## 6. 바꾸는 파일

| 파일 | 바꾸는 내용 |
|---|---|
| `index.html` | 왼쪽 메뉴로 합치기, 탭마다 `col-main`/`col-side` 나누기, 갈무리 글씨 불러오기, 게임 빈 화면 안내 추가 |
| `css/style.css` | 색·글씨·도트 규칙으로 전면 수정, 가로 배치와 좁은 창 배치 |
| `js/mascot.js` | 우왕이·알 도트 그림, 글자 지도 → SVG 함수 |
| `js/pixel-icons.js` (새 파일) | 도트 아이콘 모음 |
| `js/pet.js` | 하트·똥·효과를 도트 아이콘으로, 눈동자 한 칸 단위 |
| `js/games.js` | 게임 목록을 숨기지 않기, 게임 빈 화면 안내 켜고 끄기 |
| `js/app.js` | 주소 끝의 `#travel` 같은 표시로 첫 탭 고르기 (스크린샷 확인용) |
| `README.md` | 화면 설명과 폴더 구조 갱신 |

`state.js`, `travel.js`, `community.js`, `minigame.js`, `notify.js`, `audio.js`, `data.js`의 동작은 바꾸지 않는다. 화면에 넣는 이모지 정도만 손댈 수 있다.

## 7. 오류·예외 처리

- **글씨체를 못 불러올 때(인터넷 없음):** 기본 글씨체로 보이고 배치는 깨지지 않아야 한다.
- **저장 데이터:** 형식을 바꾸지 않으므로 지금 키우던 우왕이가 그대로 이어진다.
- **이미 쓰던 기능:** 말 걸기, 길게 눌러 걷기, 톡 눌러 쳐다보기, 씻기기, 똥, 옷 입히기, 진화, 여행, 게임 3종, 커뮤니티는 모두 그대로 동작해야 한다.

## 8. 확인 방법

자동 테스트가 없으므로 아래처럼 확인한다.

1. **스크린샷:** 화면 없는 Edge로 1280×800과 800×900(좁은 창) 크기로 4개 탭을 찍는다. 탭은 주소 끝에 `#pet`/`#travel`/`#games`/`#community`를 붙여 고른다.
2. **오류 확인:** 같은 방법으로 열었을 때 콘솔에 오류가 없는지 본다.
3. **알에서 깨어난 뒤 모습:** 가상 시간을 35초 이상 흘려서 확인한다.
4. **손으로 확인할 것 (사용자):** 돌보기 8개, 말 걸기, 걷기·쳐다보기, 여행 한 번(1분), 게임 3종, 글쓰기.
