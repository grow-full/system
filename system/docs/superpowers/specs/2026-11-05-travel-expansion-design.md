# 여행 확장 설계: 출발지·요금·좌석·국내 교통수단·창밖 하늘·집중 모드

작성일: 2026-11-05

## 목표

여행 탭을 "목적지만 고르고 기다리는 화면"에서 "실제로 표를 사서 떠나는 여행"으로 넓힌다.
그리고 같은 여행 화면을 공부 타이머(집중 모드)로도 쓸 수 있게 한다.

## 결정 사항 요약

| 항목 | 결정 |
|---|---|
| 출발지 | 드롭다운으로 자유 선택. 비행기는 국내 공항 8곳, KTX·버스·배는 출발 도시 |
| 화폐 | 기존 코인을 그대로 사용 (별도 포인트 없음) |
| 요금 | 거리 기반 + 수단 배수 + 등급 배수 |
| 첫 여행 | 앱에서 처음 하는 여행 1회 무료 (여행 기록이 0개일 때) |
| 좌석 | 모든 수단에서 배치도로 좌석 번호 직접 선택, 등급마다 가격 다름 |
| 국내 교통수단 | 비행기, KTX, 고속버스, 배 |
| 국내 여행지 | 대표 관광지 6곳 추가 (기존 제주 포함 7곳) |
| 창밖 하늘 | 기기의 현재 시각에 따라 새벽·낮·노을·밤 |
| 집중 모드 | 출발 전에 모드 선택. 요금은 일반 여행과 같음. 화면 이탈 시 타이머 멈춤 |
| 코스튬 | 누적 집중 시간 단계별 지급 (1·5·10·30·50·100시간) |
| 취소·포기 | 환불 없음. 집중 모드 포기 시 그때까지 집중한 시간은 누적에 반영 |
| 확인 방법 | 별도 테스트 페이지 없이, 단계마다 브라우저에서 실제로 실행해 확인 |

## 여행 흐름

```
① 모드 선택: 일반 여행 / 📚 집중 모드
② 교통수단 선택: ✈️ 비행기 / 🚄 KTX / 🚌 고속버스 / ⛴️ 배  (해외 여행지는 ✈️만)
③ 출발지 드롭다운 → 도착지 드롭다운 (선택한 수단·출발지로 갈 수 있는 곳만 표시)
④ 좌석 배치도에서 등급과 좌석 선택 → 요금 표시
⑤ 코인 결제 (첫 여행은 무료) → 탑승권/승차권 발권
⑥ 탑승 → 창밖 풍경(현재 시각 반영) + 카운트다운
   - 일반: 지금처럼 실제 시간으로 흐름. 앱을 닫아도 계속 진행
   - 집중: 화면을 벗어나면 멈추고, 돌아오면 이어서 진행
⑦ 도착 → 여권 스탬프·기념품. 집중 모드는 누적 시간 반영과 코스튬 지급
```

- 기다리는 시간은 지금처럼 실제 소요시간이 기본값이고, 시·분·초 조절과 빠른 선택을 그대로 쓸 수 있다.
- 요금은 고른 소요시간이 아니라 경로의 거리로 정한다.
- 화면 문구는 수단에 맞게 바꾼다. 예: 비행기는 "탑승권", KTX·버스·배는 "승차권"이다.

## 데이터

### 국내 출발 공항 (비행기)

인천(ICN), 김포(GMP), 김해(PUS), 제주(CJU), 대구(TAE), 청주(CJJ), 광주(KWJ), 양양(YNY).
공항마다 이름, 코드, 위도·경도를 둔다.

### 출발 도시 (KTX·고속버스·배)

서울, 부산, 대구, 대전, 광주, 목포, 여수.
도시마다 KTX역, 버스터미널, 항구가 있는지 표시한다.

### 국내 여행지

- 기존: 제주도
- 추가: 서울, 부산, 경주, 강릉, 전주, 여수

새 여행지에도 기존 여행지와 같은 항목(아이콘, 색, 하늘, 풍경, 특산품, 기념품, 의상, 꿀팁)을 모두 채운다.
국내 여행지에는 도착 공항 코드를 둔다. 공항이 없는 곳은 가장 가까운 공항을 쓰고, 비행기로 갈 수 없는 곳은 비워 둔다.

### 해외 여행지

기존 데이터에 위도·경도만 추가한다. 해외는 비행기로만 갈 수 있고, 출발지는 국제선이 있는 공항(인천, 김포, 김해, 제주, 대구, 청주)으로 제한한다.

### 국내 경로표 (KTX·버스·배)

```js
{ from: 'seoul', to: 'busan', mode: 'ktx', km: 400, minutes: 150 }
{ from: 'busan', to: 'jeju',  mode: 'ship', km: 290, minutes: 720 }
```

- 경로표에 없는 조합은 도착지 목록에 나오지 않는다.
- 출발 도시와 도착지가 같은 조합은 넣지 않는다.
- 국내 비행기 경로는 경로표 없이 위경도로 거리를 계산하고, 소요시간은 `30분 + 거리 km ÷ 8`(약 시속 480km)로 정한다. 직항이 없는 조합도 허용한다.
- 해외 비행기의 소요시간은 기존 `minutes` 값(인천 기준)을 쓰고, 다른 공항에서 출발하면 두 공항 사이 거리 차이만큼 보정한다.

### 거리

비행기는 출발 공항과 도착지의 위경도로 대권거리(하버사인 공식)를 계산한다. 육로와 바닷길은 경로표의 `km`를 쓴다.

## 요금

```
요금 = round((5 + 거리km ÷ 100) × 수단 배수 × 등급 배수)
```

| 수단 | 수단 배수 | 등급 (등급 배수) | 좌석 배치 |
|---|---|---|---|
| ✈️ 비행기 | 1.0 | 이코노미(×1) / 비즈니스(×2) / 퍼스트(×3) | 3-3 / 2-2 / 1-1 |
| 🚄 KTX | 0.8 | 일반실(×1) / 특실(×1.5) | 2-2 / 2-1 |
| 🚌 고속버스 | 0.6 | 일반(×1) / 우등(×1.3) / 프리미엄(×1.6) | 2-2 / 2-1 / 1-1 |
| ⛴️ 배 | 0.7 | 일반석(×1) / 객실(×2) | 좌석 / 방 번호 |

- 예: 서울→부산 KTX 일반실은 약 7코인, 인천→도쿄 이코노미는 약 18코인, 인천→파리 이코노미는 약 95코인이다.
- 게임 한 판에 코인 5~15개(`점수 ÷ 10`)를 버는 것을 기준으로 잡은 값이다. 실제로 써 보고 조정한다.
- 여행 기록이 0개면 요금을 0으로 표시하고 "첫 여행 무료 🎁" 배지를 붙인다.
- 코인이 부족하면 발권 버튼을 비활성화하고 "코인이 부족해요. 게임으로 모아 보세요!"라고 안내한다.
- 결제는 발권 시점에 한 번만 한다.

## 좌석 배치도

- 수단·등급마다 줄 수와 배치 형태를 데이터로 둔다.
- 좌석 번호 규칙:
  - 비행기: `12A`처럼 줄 번호 + 열 글자
  - KTX: `5호차 12A`
  - 버스: `1`, `2`, `3`처럼 번호만
  - 배 객실: `객실 203`
- 창가 좌석은 따로 표시한다.
- 이미 찬 좌석은 무작위로 20~40% 정도 막는다. 배치도를 열 때마다 새로 정한다.
- 좌석을 고르기 전에는 발권 버튼을 누를 수 없다.
- 등급을 바꾸면 배치도와 요금이 바로 바뀌고, 고른 좌석은 초기화된다.

## 창밖 하늘 (`sky.js`)

기기의 현재 시각 기준:

| 시각 | 단계 | 표현 |
|---|---|---|
| 05~07시 | 새벽 | 보라·분홍빛 그라데이션 |
| 07~17시 | 낮 | 파란 하늘, 흰 구름 |
| 17~19시 | 노을 | 주황·붉은 그라데이션 |
| 19~05시 | 밤 | 짙은 남색, 별과 달, 어두운 구름 |

- 탑승 중에는 1분마다 다시 확인해서, 비행 중에 해가 지면 창밖도 바뀐다.
- 수단별 풍경:
  - 비행기: 구름
  - KTX·버스: 산·나무·건물 실루엣이 옆으로 지나감
  - 배: 바다 물결

## 집중 모드 (`focus.js`)

### 화면

- 탈것, 창밖 하늘, 남은 시간, 이번에 집중한 시간만 크게 보인다.
- 상단바와 탭 메뉴는 숨긴다.
- "그만하기" 버튼만 남긴다. 누르면 확인창을 띄운다.

### 멈춤과 재개

- `visibilitychange`(다른 탭, 창 최소화)나 `blur`(다른 창 선택)가 일어나면 멈춘다.
- `focus`와 함께 화면이 다시 보이면 이어서 진행한다.
- 돌아오면 "⏸️ 화면을 벗어나서 멈췄어요"라는 안내를 잠깐 보여 준다.
- 앱을 닫았다가 다시 열면 멈춘 상태에서 이어서 시작한다. 닫혀 있던 시간은 세지 않는다.
- 진행 시간은 시작 시각이 아니라 실제로 흐른 시간(`elapsed`, 초)으로 저장한다.
  - 화면이 보이는 동안 1초마다 늘린다.
  - 저장은 몇 초마다 한 번씩, 그리고 멈출 때 한다.

### 누적과 보상

- 실제로 흐른 집중 시간만 `focusTotal`(초)에 더한다.
- 도착하거나 그만둘 때 모두 반영한다.
- 일반 여행처럼 도착하면 스탬프와 첫 방문 기념품을 받는다. 중간에 그만두면 받지 않는다.
- 중간에 그만두면 요금은 돌려주지 않는다.
- 집중 모드 보너스 코인은 없다.

### 코스튬 6종

`OUTFITS`와 같은 형식으로 추가하고, 기존 옷장 슬롯을 그대로 쓴다.

| 누적 시간 | 코스튬 | 슬롯 |
|---|---|---|
| 1시간 | ✏️ 연필 | 손 |
| 5시간 | 👓 공부 안경 | 얼굴 |
| 10시간 | 🎗️ 필승 머리띠 | 머리 |
| 30시간 | 🧣 독서 목도리 | 목 |
| 50시간 | 🎓 학사모 | 머리 |
| 100시간 | 🏅 금메달 | 목 |

- 단계를 넘는 순간 축하 안내와 함께 옷장에 넣는다. 한 번에 여러 단계를 넘으면 모두 지급한다.
- 여행 탭에 "총 집중 ⏱️ 12시간 30분 · 다음 코스튬까지 17시간 30분"을 보여 준다.
- 모든 단계를 다 받으면 "모든 코스튬을 모았어요"라고 보여 준다.

## 저장 데이터 (`state.js`)

- 비행 정보(`flight`/`ticket`)에 새 항목을 추가한다.
  - `mode`: `'normal' | 'focus'`
  - `transport`: `'plane' | 'ktx' | 'bus' | 'ship'`
  - `from`: 출발 공항·도시 id
  - `seatClass`: 좌석 등급
  - `fare`: 낸 요금
  - `elapsed`: 집중 모드에서 실제로 흐른 시간(초)
- 새 최상위 항목 `focusTotal`의 기본값은 0이다.
- 기존 저장 데이터를 불러올 때 빠진 항목은 기본값으로 채운다.
  - 진행 중인 예전 비행은 `mode: 'normal'`, `transport: 'plane'`, `from: 'ICN'`으로 본다.
- 첫 여행 무료 여부는 여행 기록(여권 스탬프)이 0개인지로 판단한다. 이미 여행해 본 기존 사용자는 무료를 받지 않는다.

## 예외 처리

- 선택한 수단·출발지로 갈 수 있는 도착지가 없으면 도착지 드롭다운에 "갈 수 있는 곳이 없어요"를 표시하고, 다음 단계로 넘어가지 못하게 한다.
- 수단을 바꿔서 기존 출발지·도착지가 맞지 않게 되면, 첫 번째로 가능한 값으로 바꾼다.
- 결제 직전에 코인을 다시 확인해서, 그사이 코인이 줄었으면 발권하지 않는다.
- 이미 여행 중이면 새 여행을 시작할 수 없다 (기존 동작 유지).

## 구현 순서

단계마다 실제로 실행해서 확인하고 커밋한다.

1. 경로·요금 + 출발지 드롭다운 + 첫 여행 무료 (`routes.js`)
2. 좌석 배치도 + 등급별 가격 (`seatmap.js`)
3. 국내 교통수단(KTX·버스·배) + 국내 대표 관광지 6곳
4. 시간에 따른 창밖 하늘 (`sky.js`)
5. 집중 모드 + 코스튬 (`focus.js`)
