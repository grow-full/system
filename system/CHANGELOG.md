# 변경사항

## 2026-11-05 · 여행 기능 확장

여행 탭을 "목적지만 고르고 기다리는 화면"에서 "표를 사서 떠나는 여행"으로 넓혔습니다.
같은 여행 화면을 공부 타이머(집중 모드)로도 쓸 수 있습니다.

### 한눈에 보기

| 기능 | 이전 | 이후 |
|---|---|---|
| 출발지 | 인천 고정 | 드롭다운으로 선택 (국내 공항 8곳 / 출발 도시 7곳) |
| 교통수단 | 비행기만 | 비행기, KTX, 고속버스, 배 |
| 여행지 | 15곳 | 21곳 (국내 6곳 추가: 서울, 부산, 경주, 강릉, 전주, 여수) |
| 요금 | 없음 (무료) | 거리·수단·등급으로 계산해 코인으로 결제, 첫 여행 무료 |
| 좌석 | 무작위 배정 | 배치도에서 좌석 번호와 등급을 직접 선택 |
| 창밖 풍경 | 늘 낮 하늘 | 지금 시각에 맞춰 새벽·낮·노을·밤, 수단마다 다른 풍경 |
| 공부 | 없음 | 집중 모드 (화면을 벗어나면 멈추는 타이머) + 공부 코스튬 6종 |
| 안내 방송 | 짧은 여행에서 끊기기도 함 | 마지막 방송이 끝난 뒤 도착 |

### 1. 출발지와 교통수단
- 출발 전에 교통수단을 고릅니다: ✈️ 비행기, 🚄 KTX, 🚌 고속버스, ⛴️ 배
- **비행기**는 국내 공항 8곳(인천, 김포, 김해, 제주, 대구, 청주, 광주, 양양) 중에서 출발합니다.
  - 해외는 국제선이 있는 공항에서만 갈 수 있습니다.
- **KTX·버스·배**는 출발 도시(서울, 부산, 대구, 대전, 광주, 목포, 여수)를 고릅니다.
  - 그 수단으로 실제 갈 수 있는 곳만 도착 목록에 나옵니다. 예: 제주는 비행기나 배로만 갈 수 있습니다.

### 2. 국내 여행지 6곳 추가
서울, 부산, 경주, 강릉, 전주, 여수를 추가했습니다.
여행지마다 대표 먹거리, 기념품, 의상, 여행 꿀팁이 들어 있습니다.

### 3. 거리별 요금 (코인)
- 요금 = `(5 + 거리km ÷ 100) × 수단 배수 × 등급 배수`를 반올림합니다.
  - 수단 배수: 비행기 1, KTX 0.8, 버스 0.6, 배 0.7
- 코인은 늘 자연수이고, 최소 1코인입니다.
- **첫 여행은 무료**입니다 🎁

| 예시 | 요금 |
|---|---|
| 서울 → 부산, KTX 일반실 | 🪙 7 |
| 인천 → 도쿄, 이코노미 | 🪙 18 |
| 인천 → 파리, 이코노미 | 🪙 94 |

- 코인이 부족하면 발권 버튼이 잠기고, 몇 코인이 더 필요한지 알려 줍니다.
- 타기 전에 표를 취소하면 요금을 돌려받습니다. 출발한 뒤에 취소하면 돌려받지 못합니다.

### 4. 좌석 고르기와 등급
배치도에서 좌석 번호를 직접 고릅니다.
회색은 이미 찬 좌석이고, 파란 테두리는 창가(배 객실은 바다 전망)입니다.

| 수단 | 등급 (요금 배수) | 좌석 번호 예 |
|---|---|---|
| ✈️ 비행기 | 이코노미 ×1 · 비즈니스 ×2 · 퍼스트 ×3 | 23A |
| 🚄 KTX | 일반실 ×1 · 특실 ×1.5 | 5호차 3B |
| 🚌 고속버스 | 일반 ×1 · 우등 ×1.3 · 프리미엄 ×1.6 | 7 |
| ⛴️ 배 | 일반석 ×1 · 객실 ×2 | 객실 205 |

발권하면 수단에 맞는 표가 나옵니다: 탑승권, KTX 승차권, 고속버스 승차권, 승선권

### 5. 시간에 따라 바뀌는 창밖
기기의 현재 시각에 맞춰 창밖 하늘이 바뀝니다. 여행 중에 해가 지면 창밖도 같이 바뀝니다.

| 시각 | 하늘 |
|---|---|
| 05~07시 | 새벽 (보라·분홍) |
| 07~17시 | 낮 (파란 하늘) |
| 17~19시 | 노을 (주황) |
| 19~05시 | 밤 (별과 달) |

창 모양과 풍경도 수단마다 다릅니다.
- 비행기: 둥근 창 밖으로 구름이 지나갑니다.
- KTX·버스: 넓은 창 밖으로 산과 마을이 지나갑니다. KTX가 더 빠르게 지나갑니다.
- 배: 동그란 창 밖으로 바다 물결이 보입니다.

### 6. 집중 모드 (공부 타이머)
- 여행을 떠나기 전에 🧳 일반 여행과 📚 집중 모드 중 하나를 고릅니다.
- 집중 모드로 탑승하면 상단바와 탭이 사라지고 **탈것, 창밖, 남은 시간, 이번에 집중한 시간**만 보입니다.
- **화면을 벗어나면 타이머가 멈춥니다.**
  - 다른 탭으로 가거나, 창을 최소화하거나, 다른 창을 누르면 멈춥니다.
  - 돌아오면 "화면을 벗어나서 ○초 동안 멈췄어요" 안내와 함께 이어서 흐릅니다.
  - 앱을 닫아 둔 시간도 세지 않습니다.
- 요금은 일반 여행과 같습니다.
- 중간에 그만두면 그때까지 집중한 시간은 기록되고, 요금은 돌려받지 못합니다.
- 누적 집중 시간에 따라 **공부 코스튬**을 받아 옷장에서 입힐 수 있습니다.

| 누적 시간 | 코스튬 |
|---|---|
| 1시간 | ✏️ 연필 |
| 5시간 | 👓 공부 안경 |
| 10시간 | 🎗️ 필승 머리띠 |
| 30시간 | 🧣 독서 목도리 |
| 50시간 | 🎓 학사모 |
| 100시간 | 🏅 금메달 |

### 7. 안내 방송 개선
- 짧은 여행에서 방송이 중간에 끊기던 문제를 고쳤습니다.
- 방송 시각을 읽는 데 걸리는 시간에 맞춰 정하고, **마지막 도착 방송이 끝난 뒤에 도착**합니다.
- 너무 짧은 여행에서는 환영 방송을 빼서, 두 방송이 서로 끊지 않게 했습니다.
- 수단마다 방송 문구가 다릅니다. 예: KTX "열차가 출발합니다", 배 "배가 출항합니다"

### 기존 데이터
- 이전 버전에서 저장한 데이터는 그대로 이어서 쓸 수 있습니다.
- 이전 버전에서 비행 중이던 여행은 인천발 일반 비행으로 이어집니다.
