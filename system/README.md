# 우왕이와 떠나는 여행

학교 마스코트 **우왕이**를 다마고치처럼 키우면서, 함께 가상 여행을 떠나는 웹앱입니다.
설치 없이 브라우저에서 바로 실행됩니다.

## 화면

- **레트로 도트(픽셀) 스타일:** 크림색 LCD 바탕에 버건디(충북대 대표색) 글씨·테두리, 한글 도트 글씨 [갈무리](https://github.com/quiple/galmuri)(인터넷에서 불러오며, 인터넷이 없으면 기본 글씨체로 보입니다). 색은 `css/style.css` 맨 위 변수에서 바꿉니다.
- **PC용 가로 화면:** 왼쪽 메뉴(레벨·탭·코인·알림) + 가운데 큰 화면 + 오른쪽 패널. 창 가로가 900px보다 좁으면 **휴대폰 화면**으로 바뀝니다: 위쪽에 레벨·코인·알림 막대, 아래쪽에 탭 막대, 내용은 한 줄로 쌓입니다. 게임은 고르면 목록이 숨고 게임 화면만 보입니다.
- 주소 끝에 `#travel`, `#games`, `#community`를 붙이면 그 탭으로 시작합니다.

## 실행 방법

- `index.html`을 더블클릭해서 브라우저(Chrome, Edge 권장)로 엽니다.
- 휴대폰에서 보려면 같은 와이파이에서 아래처럼 간단한 서버를 띄우고 `http://PC의IP:8000`으로 접속합니다.

  ```bash
  python -m http.server 8000
  ```

- Python이 없는 Windows에서는 이 폴더에서 아래 명령으로 같은 서버를 띄울 수 있습니다 (끄기: Ctrl + C).

  ```powershell
  powershell -ExecutionPolicy Bypass -File serve.ps1
  ```

- **🐾 산책 탭**은 구글 스트리트 뷰를 쓰기 때문에 더블클릭으로는 열리지 않습니다. 위 서버를 띄우고 `http://localhost:8000`으로 열고, 아래 [산책 탭 설정](#산책-탭을-쓰려면-google-maps-api-키)을 먼저 해 주세요.

## 탭별 기능

### 🐣 우왕이 (다마고치 방식으로 키우기)
- 우왕이가 방 안을 돌아다니고, 말풍선으로 필요한 것을 알려 줍니다. 우왕이를 누르면 쓰다듬기, 알일 때는 톡톡 두드리기.
- 알 → 아기 → 어린이(Lv.3) → 어른(Lv.5)으로 자랍니다.
- **어른 모습은 키운 방법에 따라 5가지로 갈라집니다** (`js/state.js`의 `decideForm`):

  | 모습 | 조건 (위에서부터 먼저 확인) |
  |---|---|
  | 😪 꾀죄죄 우왕이 | 돌봄 실수 4번 이상 |
  | ✈️ 여행가 우왕이 (탐험 모자) | 여행 3번 이상, 게임 판 수의 절반 이상 |
  | 🎮 게이머 우왕이 (헤드폰) | 게임 6판 이상 |
  | 🌟 반짝 우왕이 (금빛, 반짝이) | 돌봄 실수 1번 이하 |
  | 💪 듬직 우왕이 (진한 눈썹) | 그 밖의 경우 |

  키워 본 모습은 **우왕이 도감**에 남고, 처음부터 다시 키워도 사라지지 않습니다.
- **씻기기:** 깨어 있는 시간 2시간마다, 그리고 놀아주기를 끝내면 우왕이가 꼬질꼬질해집니다(몸에 얼룩, 파리 🪰). 더러운 동안에는 행복이 2배 빨리 줄어듭니다. 🛁 씻기기로 깨끗하게 해 주면 경험치 +5. 간격은 `js/state.js`의 `CARE.dirtyEvery`로 조절합니다.
- **말 걸기:** 안녕! / 사랑해 / 배고파? / 기분 어때? / 어디 가고 싶어? / 잘 자 중에서 골라 말을 걸면, 우왕이가 지금 상태(배고픔, 행복, 아픔, 똥, 시간대, 안 가 본 여행지)에 맞게 대답합니다. 수치는 바뀌지 않습니다. 알일 때, 잘 때, 여행 중에는 말을 걸 수 없습니다.
  - 입력칸에 직접 써서(40자까지) 말을 걸 수도 있습니다. 말 속의 낱말(예: 배고·밥, 사랑, 이름, 고마워, 귀여워, 바보, 여행, 기분, 안녕)을 보고 대답하고, 모르는 말에는 "무슨 말인지 잘 모르겠어요" 같은 대답을 합니다. 낱말과 대답은 `js/pet.js`의 `TALK_WORDS`, `replyTo`에서 고칠 수 있습니다.
- **톡 눌러 쳐다보기:** 방 안의 빈 곳을 짧게 누르면 우왕이가 누른 곳(위·아래·왼쪽·오른쪽) 쪽으로 고개(몸)를 기울여 2초 동안 쳐다봅니다. 실제 우왕이 그림은 눈이 그림에 그려져 있어서 눈동자 대신 몸을 기울입니다 (`js/pet.js`의 `GAZE_MS`로 시간 조절). 알일 때, 잘 때, 놀아주기 중에는 안 됩니다.
- **길게 눌러 걷기:** 방 안의 빈 곳을 0.3초쯤 꾹 누르고 있으면, 누른 곳이 우왕이보다 오른쪽이면 오른쪽으로, 왼쪽이면 왼쪽으로 걸어갑니다. 손을 떼거나 벽에 닿으면 멈춥니다. 걷는 모습과 빠르기는 우왕이 몸 동작(`js/mascot.js`의 `MOTION.walk`)을 그대로 씁니다.
- **옷장:** 여행지에 처음 도착하면 그곳의 의상(21종)을, 집중 모드 시간이 쌓이면 공부 코스튬(6종)을 받습니다. 머리·얼굴·목·손에 하나씩 입힐 수 있습니다 (`js/data.js`의 `OUTFITS`).
- 돌보기 버튼: 밥, 간식(코인), 놀아주기(우왕이가 볼 방향 맞히기 5판), 청소, 씻기기, 약, 불 끄기/켜기, 말 걸기.
- 배고픔·행복 하트, 나이, 몸무게, 돌봄 실수를 화면에서 바로 볼 수 있습니다.
- 시간이 지나면 배고픔·행복이 줄고 똥을 쌉니다 (45분마다 1번, 그리고 밥·간식을 먹으면 5분 뒤에 반드시 1번. `js/state.js`의 `CARE.poopEvery`, `CARE.poopAfterMeal`로 조절). 똥을 오래 두거나 굶기면 병에 걸립니다. 앱을 꺼 둔 시간도 계산됩니다.
- 밤 10시~아침 8시에는 잠을 잡니다. 불을 꺼 주지 않으면 돌봄 실수가 됩니다.
- 여행 중에는 기내에서 돌봐 줘서 수치가 줄지 않습니다.
- **돌봄 알림:** 왼쪽 메뉴 아래의 종 버튼으로 켜고 끕니다(기본은 꺼짐). 켜 두면 약, 똥 치우기, 밥, 놀아주기, 불 끄기가 새로 필요해질 때 한 번씩 알려 줍니다. 앱이 다른 창이나 최소화 상태면 브라우저 알림으로, 다른 탭을 보고 있으면 화면 아래 안내로 알립니다 (`js/notify.js`).
  - 브라우저 탭이 열려 있어야 합니다. 앱을 완전히 닫으면 알림이 오지 않습니다.
  - 브라우저 알림은 https 주소나 이 PC의 파일·localhost에서만 됩니다. 휴대폰에서 `http://PC의IP:8000`으로 접속하면 쓸 수 없습니다.

### ✈️ 여행
- **모드:** 출발 전에 🧳 일반 여행 또는 📚 집중 모드를 고릅니다.
- **교통수단과 출발지:** ✈️ 비행기, 🚄 KTX, 🚌 고속버스, ⛴️ 배 중에서 고릅니다.
  - 비행기는 국내 공항 8곳(인천, 김포, 김해, 제주, 대구, 청주, 광주, 양양) 중에서 출발합니다. 해외는 국제선이 있는 공항에서만 갈 수 있습니다.
  - KTX, 버스, 배는 출발 도시(서울, 부산, 대구, 대전, 광주, 목포, 여수)를 고릅니다. 도착 목록에는 그 수단으로 갈 수 있는 곳만 나옵니다 (`js/routes.js`의 `GROUND_ROUTES`).
- **여행지 21곳:** 국내 7곳(서울, 부산, 경주, 강릉, 전주, 여수, 제주)과 해외 14곳입니다.
- 기다릴 시간은 **실제 소요시간이 기본값**이고, 시·분·초 ▲▼ 버튼(누르고 있으면 연속 변경)이나 빠른 선택으로 바꿀 수 있습니다.
- **좌석 고르기:** 배치도에서 좌석 번호를 직접 고릅니다. 회색은 이미 찬 좌석, 파란 테두리는 창가입니다 (`js/seatmap.js`).

  | 수단 | 등급 (요금 배수) |
  |---|---|
  | ✈️ 비행기 | 이코노미 ×1 · 비즈니스 ×2 · 퍼스트 ×3 |
  | 🚄 KTX | 일반실 ×1 · 특실 ×1.5 |
  | 🚌 고속버스 | 일반 ×1 · 우등 ×1.3 · 프리미엄 ×1.6 |
  | ⛴️ 배 | 일반석 ×1 · 객실 ×2 |

- **요금(코인):** `(5 + 거리km ÷ 100) × 수단 배수 × 등급 배수`를 반올림합니다. 코인은 늘 자연수이고 최소 1코인입니다. 수단 배수는 비행기 1, KTX 0.8, 버스 0.6, 배 0.7입니다.
  - 예) 서울→부산 KTX 일반실 7코인, 인천→도쿄 이코노미 18코인, 인천→파리 이코노미 94코인
  - **첫 여행은 무료**입니다 🎁.
  - 요금은 발권할 때 냅니다. 타기 전에 표를 취소하면 돌려받고, 출발한 뒤 취소하면 돌려받지 못합니다.
- 발권 → 탑승 → 창밖 풍경과 카운트다운, 방송, 소음·빗소리·음악.
- **창밖 풍경은 지금 시각에 맞춰** 새벽(5~7시), 낮(7~17시), 노을(17~19시), 밤(19~5시)으로 바뀝니다. 비행기는 구름, KTX·버스는 산과 마을, 배는 바다가 지나갑니다 (`js/sky.js`).
- 일반 여행은 **실제 시간으로 흐르기 때문에** 다른 탭을 쓰거나 앱을 닫아도 계속 가고, 시간이 되면 도착합니다.
- 도착하면 여권 스탬프와 첫 방문 기념품을 받고, 그 여행지 꿀팁 게시판으로 바로 갈 수 있습니다.

### 📚 집중 모드 (공부 타이머)
- 탑승하면 상단바와 탭이 사라지고 **탈것, 창밖, 남은 시간, 이번에 집중한 시간**만 보입니다.
- **화면을 벗어나면 타이머가 멈춥니다.** 다른 탭으로 가거나, 창을 최소화하거나, 다른 창을 누르면 멈추고, 돌아오면 이어서 흐릅니다. 앱을 닫아 둔 시간도 세지 않습니다 (`js/focus.js`).
- 요금은 일반 여행과 같습니다. 끝까지 가면 일반 여행처럼 도착 보상을 받습니다.
- 중간에 **그만하기**를 누르면 그때까지 집중한 시간은 기록되고, 요금은 돌려받지 못합니다.
- 누적 집중 시간에 따라 **공부 코스튬**을 받아 옷장에서 입힐 수 있습니다 (`js/data.js`의 `FOCUS_COSTUMES`).

  | 누적 | 코스튬 |
  |---|---|
  | 1시간 | ✏️ 연필 |
  | 5시간 | 👓 공부 안경 |
  | 10시간 | 🎗️ 필승 머리띠 |
  | 30시간 | 🧣 독서 목도리 |
  | 50시간 | 🎓 학사모 |
  | 100시간 | 🏅 금메달 |

### 🐾 산책
학교(충북대학교) 곳곳의 360° 사진(구글 스트리트 뷰) 위에서 우왕이와 산책합니다 (`js/walk.js`).

- **산책 전 체크:** 건강, 배고픔, 심심함(행복의 반대)을 보여 줍니다. 아프거나 알이거나 여행 중이면 산책을 나갈 수 없습니다.
- **출발 장소 고르기:** 이름표가 있는 장소를 두 칸 바둑판에서 고릅니다. 다음 버튼은 화면 아래에 늘 떠 있습니다.
- **옷 입기:** 옷 갈아입는 방(창밖이 실제 시간대를 따라감) 아래의 옷 상자에서, 기본 옷 2벌(학사모·뿔테 안경)과 여행에서 받은 의상, 🎧 헤드셋을 골라 입고 나갑니다. 여행 의상은 우왕이 탭 옷장과 같이 바뀌고, 기본 옷은 산책에서만 입습니다(우왕이 탭에는 나오지 않음). 옷을 입히면 우왕이가 그 옷에 맞는 말을 하고, **🎲 오늘의 코디**를 누르면 가진 옷 중에서 무작위로 골라 입혀 줍니다. 산책을 끝내거나 산책 중에 다른 탭으로 가면 옷과 헤드셋을 모두 벗습니다(끝 요약에는 입고 나갔던 모습으로 나옵니다).
- **걷기:** 방향키(또는 화면 오른쪽 아래 버튼)로 우왕이를 한 걸음씩 움직입니다. 화면을 끌어서 둘러볼 수 있습니다.
- **🧭 어디로 갈까요?:** 🗺️ 지도와 📋 목록(가까운 순)을 한 칸에서 바꿔 봅니다. 지도의 📍나 목록의 장소를 누르면 우왕이가 그곳까지 걸어갑니다. 거리는 두 사진 위치 사이의 직선거리입니다.
- **우왕이 감상과 배경음:** 장소마다 우왕이가 하는 말과 분위기 음악(물가, 숲, 새소리, 도서관 경쾌한 피아노, 학생회관 통기타, 기숙사 오르골 자장가, 캠퍼스, 공대, 운동장, 하늘)이 다릅니다.
- **시간대:** 실제 시계에 맞춰 아침(5~10시)과 저녁 노을(17~19시)에는 화면 색이 살짝 바뀌고(낮과 밤에는 그대로), 우왕이가 가끔 그 시간대에 맞는 말을 합니다.
- **산책 끝 요약:** 산책 끝내기를 누르면 걸음, 시간, 받은 코인, 들른 곳, 새 도장, 만난 친구를 한 장으로 보여 줍니다.
- **숨은 친구:** 캠퍼스 몇 곳에 우왕이 친구 5명(좌왕이, 스테디, 타나, 느루, 은송이)이 숨어 있습니다. 출발 장소 고르기 화면에 안내가 나오고, 인사한 친구는 산책 화면 아래 **🤝 찾은 친구** 칸에 얼굴로 모입니다(어디 있는지는 알려 주지 않습니다). 친구 위치는 `js/maps-config.js`의 `WALK_FRIENDS`에서 고칩니다.
- **장소 이름:** 이름표가 없는 사진은 150m 안에서 가장 가까운 이름 있는 장소를 따서 "○○ 근처"로, 그보다 멀면 "캠퍼스 어딘가"로 나옵니다. "근처"에서는 그 장소의 감상·배경음을 빌려 쓰지만 도장과 친구는 없습니다.
- **보상:** 산책 화면의 🎁 산책 보상 칸에서 다음 코인·하트·도장까지 남은 양을 막대로 보여 주고, 아래에 보상 받는 방법을 "하는 일 → 받는 것"으로 정리해 둡니다.
  - 산책 10분마다 🪙 5개를 받습니다.
  - 100걸음마다 💗 행복이 1 오릅니다.
  - 장소에서 50걸음 이상 걸으면 🏅 도장을 받습니다(처음 받는 도장은 🪙 3개, 전부 모으면 🪙 30개).
  - 숨은 친구와 처음 인사하면 🪙 2개, 5명을 모두 찾으면 🪙 15개를 받습니다.
  - **💧 물 마시기:** 80걸음쯤 걸으면 우왕이가 목말라하고 버튼이 파랗게 콩콩 뜁니다. 그때 물을 마시면 다음 💗 하트까지 30걸음을 채워 줍니다(목마르지 않을 때 마시면 보상 없음). 마실 때는 텀블러의 마시는 구멍을 입에 대고 꿀꺽꿀꺽 마시며, 끝 요약에 마신 횟수가 나옵니다.
- 장소 이름표·감상·음악·아이콘은 `js/maps-config.js`에서 고칩니다. 사진에 표시되는 올린 사람 이름으로 특정 사람의 사진을 뺄 수 있습니다(`WALK_BLOCKED_AUTHORS`). 실내 교실처럼 산책에 맞지 않는 사진은 파노라마 ID로 하나씩 뺍니다(`WALK_BLOCKED_PANOS`).

## 산책 탭을 쓰려면 (Google Maps API 키)

1. [Google Cloud 콘솔](https://console.cloud.google.com)에서 프로젝트를 만들고 결제 계정을 연결합니다 (무료 사용량 안에서는 보통 요금이 나오지 않습니다).
2. **Maps JavaScript API**를 사용 설정합니다.
3. **API 및 서비스 → 사용자 인증 정보**에서 API 키를 만들고, 아래 두 제한을 겁니다.
   - 애플리케이션 제한사항: **웹사이트** → `http://localhost:8000/*`
   - API 제한사항: **Maps JavaScript API**만
4. `js/maps-key.example.js`를 같은 폴더에 `js/maps-key.js`로 복사하고 키를 넣습니다.

> `js/maps-key.js`는 `.gitignore`에 들어 있어서 GitHub에 올라가지 않습니다. 저장소가 공개라서, 키를 다른 파일에 넣어 커밋하지 마세요.

## 커뮤니티를 모두와 공유하려면 (Firebase)

1. [Firebase 콘솔](https://console.firebase.google.com)에서 프로젝트를 만들고 **웹 앱**을 추가합니다.
2. **Firestore Database**를 만듭니다.
3. 웹 앱 설정값(`apiKey`, `projectId` 등)을 `js/firebase-config.js`의 `FIREBASE_CONFIG`에 넣습니다.
4. 설정하면 글이 Firestore의 `tips` 컬렉션에 저장되고 모든 사용자에게 보입니다.

> 지금의 삭제 권한은 기기별 임의 ID로만 구분합니다. 실제로 공개하기 전에는 Firebase 로그인과 Firestore 보안 규칙을 꼭 설정해야 합니다.

## 아이디로 로그인해서 여러 기기에서 이어 하기 (Supabase)

상단의 👤 버튼으로 아이디/비밀번호를 만들고 로그인하면 게임 진행(우왕이, 레벨, 코인, 여행 기록, 최고 점수 등)이 계정에 저장됩니다. 다른 기기에서 같은 아이디로 로그인하면 이어서 할 수 있습니다.

1. Supabase 대시보드 → **SQL Editor**에서 아래를 실행합니다.

   ```sql
   create table public.saves (
     user_id    uuid primary key references auth.users on delete cascade,
     data       jsonb  not null,
     played_at  bigint not null default 0,
     updated_at timestamptz not null default now()
   );
   alter table public.saves enable row level security;
   create policy "자기 저장만 읽고 쓰기" on public.saves
     for all using (auth.uid() = user_id) with check (auth.uid() = user_id);
   ```

2. **Authentication → Sign In / Providers → Email**에서 **Confirm email을 끕니다.** 아이디는 내부적으로 `아이디@wooang.app` 형태의 이메일로 바뀌어 저장되며 실제 메일은 보내지 않습니다. 이 설정이 켜져 있으면 가입이 되지 않습니다.
3. **Project Settings → API**의 Project URL과 anon key를 `js/supabase-config.js`의 `SUPABASE_CONFIG`에 넣습니다. anon key는 공개되어도 되는 키이고, 1번의 RLS 정책 덕분에 각자 자기 저장만 볼 수 있습니다.

동작 규칙

- **가장 최근에 플레이한 기기의 진행을 씁니다.** 화면을 직접 누르거나 키를 친 시각(`playedAt`)을 기준으로 비교합니다. 그래서 켜 두기만 한 기기가 다른 기기의 진행을 덮어쓰지 않습니다.
- 플레이하면 3초 뒤 자동 저장되고, 앱을 내리거나 다른 탭으로 갈 때도 저장됩니다. 앱으로 돌아오면 다른 기기에서 더 최근에 한 진행이 있는지 확인해서 있으면 불러옵니다.
- 로그인 전에 이 기기에서 하던 진행은 **계정에 저장이 없을 때만** 계정으로 옮깁니다. 이미 저장이 있는 계정이면 계정 진행을 불러옵니다.
- 로그아웃하면 이 기기에서는 새로 시작하고, 진행은 계정에 그대로 남아 있습니다.
- 알림 켜기, 기내 방송 음성, 커뮤니티 기기 ID와 좋아요는 기기마다 따로 저장합니다.
- 비밀번호를 잊어버리면 찾을 수 없습니다(메일이 없으므로). 필요하면 Supabase 대시보드 → Authentication → Users에서 관리자가 비밀번호를 바꿔 줄 수 있습니다.

## 알아 둘 점

- **우왕이 그림:** 태어난 뒤의 우왕이는 실제 캐릭터 그림(`assets/uwang-states.png`, `assets/uwang-actions.png`)을 쓰고, 화면의 나머지(메뉴·버튼·아이콘)는 도트 스타일입니다. 몸 동작 수치는 `js/mascot.js`의 `MOTION`에서 바꿉니다.
- 비행시간은 인천 출발 직항 기준의 대략적인 시간입니다.
- 진행 상황은 브라우저의 `localStorage`에 저장됩니다.
